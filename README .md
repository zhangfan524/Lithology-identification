=============================================
README for Supporting Information
Study Title: [A multi-attention mechanism-improved ResNet18 approach for lithology identification and classification]
Corresponding Author: [Jiaming Li]
Journal: PLOS ONE
=============================================

This README file describes the content of all supporting information files included with the manuscript.

-----------------------------------------------------------------------------
File Overview (Ordered by S1-S6)
-----------------------------------------------------------------------------
1. S1_5-fold_CV_Results.xlsx
   - Description: Raw results of 5-fold cross-validation for model, including fold-specific performance metrics.
   - Contents: Fold index, training/validation split information

2. S2_Model_Performance_Comparison.xlsx
   - Description: Aggregated performance comparison of model on the test dataset.
   - Contents: Summary metrics for model, including Accuracy, Precision, Recall, F1-score.

3. S3_Model_Evaluation_Metrics.xlsx
   - Description: Detailed evaluation metrics for model on the test dataset.
   - Contents: Full list of classification/regression metrics calculated in the study.

4. S4_Model_Loss_Curves_Data.xlsx
   - Description: Training and validation loss values recorded for each attention mechanism when recognizing each rock category during model training.
   - Contents: validation loss of each attention mechanism for different rock categories.

5. S5_Code_Scripts/ (Folder)
   - Description: Source code used for model training, cross-validation, and evaluation.

6. S6_Test_Dataset/ (Folder)
   - Description: Test dataset used for model evaluation.
